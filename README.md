# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）实现的经典坦克大战（Battle City）网页版，**零依赖、单文件**，打开即可游玩。

## ✨ 功能特性

- 🎮 经典俯视角坦克对战玩法
- 🧱 可破坏的砖墙、不可破坏的钢墙、可通行的水与树林
- 🦅 需要保卫的基地（老鹰）
- 🤖 敌人 AI：随机巡逻、与玩家/基地对齐时自动开火
- 📈 三关递进，难度逐步提升
- 💥 粒子爆炸特效 + Web Audio 音效
- 📱 支持键盘与移动端触屏按键
- 🏆 计分、生命、剩余敌人、关卡 HUD

## 🎯 操作方式

| 操作 | 按键 |
|------|------|
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 / 继续 | P |
| 重新开始 | R |
| 开始游戏 | Enter / 空格 |

移动端会自动显示屏幕上的方向键与开火按钮。

## 🚀 运行方式

### 方式一：直接打开

用浏览器直接打开 `index.html` 即可游玩。

### 方式二：GitHub Pages

1. 在仓库 **Settings → Pages** 中将 Source 设为 `main` 分支根目录；
2. 访问 `https://<你的用户名>.github.io/tank-battle/`。

## 📁 文件结构

```
tank-battle/
```

## 🛠 技术说明

- 纯原生实现，无任何外部库或构建步骤
- 13×13 网格地图，半格（20px）精度移动，网格对齐 + 平滑插值动画
- Canvas 2D 渲染，`requestAnimationFrame` 游戏循环
- Web Audio API 实时合成音效

## 玩法规则

- 消灭关卡内所有敌人即可进入下一关；
- 玩家共有 3 条命，被击中或基地被毁则游戏结束；
- 小心不要打到自己家的基地！
